# SITE
Site oficial da Subuluk 3D - Impressão 3D e produtos personalizados.

## Configuração
Edite `assets/site.js` (bloco `SBK.config`):
- `GA4_ID`: ID do Google Analytics 4 (G-XXXX). Vazio = Analytics desligado.
- `EMAIL`: e-mail de contato para privacidade (aparece nas páginas legais).

O Analytics só carrega após o visitante aceitar no aviso de cookies (Google Consent Mode v2, tudo negado por padrão).
Páginas legais: `privacidade.html`, `termos.html`, `cookies.html`. SEO: `sitemap.xml`, `robots.txt`, `assets/og-image.jpg`.
