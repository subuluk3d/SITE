Conexão com o GitHub

O botão Publicar envia as fotos e o catálogo direto para o repositório do site. Para isso o painel precisa de um token do GitHub. O token fica salvo só neste navegador.

  1. Abra github.com/settings/personal-access-tokens/new (token fine-grained).
  2. Nome: “Painel Subuluk”. Expiração: 1 ano.
  3. Repository access: Only select repositories → escolha só o repositório SITE.
  4. Permissions → Repository permissions → Contents: Read and write. Não marque mais nada.
  5. Clique em Generate token, copie e cole abaixo.

Segurança: nunca envie esse token para ninguém. Use este painel só no seu computador ou celular. Se perder o aparelho, apague o token em github.com/settings/personal-access-tokens.
